# Install SSCC as an App

The Smart Student Commute Companion can be installed on your device for a better app-like experience.

## Benefits of Installing

✅ **Quick Access** - Launch from home screen or app drawer  
✅ **Faster Loading** - Cached assets load instantly  
✅ **Full Screen** - No browser UI, more screen space  
✅ **Offline Access** - View cached content without internet  
✅ **App Experience** - Feels like a native mobile app  

## How to Install

### 📱 Android (Chrome)
1. Open https://your-app-url.com in Chrome
2. Tap the menu (⋮) in the top right
3. Select **"Add to Home Screen"** or **"Install App"**
4. Tap **"Install"** in the popup
5. Find the app icon on your home screen

### 📱 Android (Samsung Internet)
1. Open the app in Samsung Internet
2. Tap the menu (☰)
3. Select **"Add page to"**
4. Choose **"Home screen"**
5. Confirm installation

### 🍎 iPhone/iPad (Safari)
1. Open https://your-app-url.com in Safari
2. Tap the **Share** button (square with arrow)
3. Scroll down and tap **"Add to Home Screen"**
4. Edit the name if desired
5. Tap **"Add"** in the top right
6. Find the app icon on your home screen

**Note**: On iOS, you must use Safari. Chrome/Firefox on iOS cannot install web apps.

### 💻 Desktop (Chrome/Edge)
1. Open https://your-app-url.com in Chrome or Edge
2. Look for the install icon (⊕) in the address bar
3. Click the install icon
4. Click **"Install"** in the popup
5. Find the app in:
   - **Windows**: Start Menu or Desktop
   - **Mac**: Applications folder or Dock
   - **Chrome OS**: App drawer

### 💻 Desktop (Firefox)
1. Open the app in Firefox
2. Look for the install icon in the address bar
3. Click and confirm installation
4. Access from browser's apps menu

## After Installing

Once installed:
- Launch the app from your home screen/app drawer
- It will open in standalone mode (no browser UI)
- Works just like a native app
- Can be uninstalled like any other app

## Uninstalling

### Android
1. Long-press the app icon
2. Select **"Uninstall"** or drag to uninstall
3. Confirm removal

### iOS
1. Long-press the app icon
2. Select **"Remove App"**
3. Choose **"Delete App"**
4. Confirm deletion

### Desktop (Windows)
1. Open Settings → Apps
2. Find "Smart Student Commute Companion"
3. Click Uninstall

### Desktop (Mac)
1. Open Applications folder
2. Find the app
3. Drag to Trash
4. Empty Trash

### Desktop (from Browser)
**Chrome/Edge:**
1. Go to chrome://apps
2. Right-click the app
3. Select "Uninstall"

## Troubleshooting

**Don't see install option?**
- Make sure you're on HTTPS (not HTTP)
- Try refreshing the page
- Check if already installed
- Try a different browser

**Install failed?**
- Check your internet connection
- Clear browser cache and try again
- Update your browser to latest version
- Ensure you have storage space

**App not working after install?**
- Check internet connection (for first launch)
- Try uninstalling and reinstalling
- Clear app cache (in browser settings)
- Contact support if issues persist

## Privacy & Permissions

The app requests:
- **Storage**: To cache app files for offline use
- **Location**: Only when you use route planning (can deny)
- **Notifications**: Only if you enable disruption alerts (optional)

We never cache:
- Your personal information
- API keys or passwords
- Private routes or history
- Location data
